# Candy Clean UI

Клиентский Fabric-мод для сервера ServerCandy DayZ (Minecraft 1.21.1).

## Назначение
Отключает навязчивые всплывающие уведомления (toasts), портящие атмосферу хардкорного выживания:
- Предупреждение о непроверяемых сообщениях чата (`UNSECURE_SERVER_WARNING` - "Невозможно проверить сообщения чата / Сообщения, отправляемые в чат этого сервера, могут быть изменены и не отражать реальное сообщение")
- Уведомления о получении ачивок / достижений (`AdvancementToast`)
- Уведомления об открытии рецептов книги рецептов (`RecipeToast`)
- Обучающие подсказки (`TutorialToast`)

## Сборка
Запустите `build_and_deploy.bat` или выполните `python build_mod.py`.
